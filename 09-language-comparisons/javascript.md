# JavaScript

JavaScript is a programming language standardized as ECMAScript. Browsers implement it to make web pages interactive, and server-side runtimes such as Node.js let developers use it beyond the browser.

## Curiosity questions and answers

### 82. Why is JavaScript used in browsers?

Browsers adopted JavaScript as a standard way for web pages to respond to user actions, update content, and communicate with servers without reloading every page. Its widespread browser support makes it a practical client-side language. Browser APIs provide access to page and device features subject to security restrictions.

### 83. Why is Node.js able to run JavaScript on servers?

Node.js embeds a JavaScript engine and supplies server-oriented APIs for files, networking, and processes. This lets JavaScript execute outside a browser. Node's event-driven, non-blocking I/O model is useful for many network services, though CPU-heavy tasks need careful handling because long synchronous work can block the event loop.
