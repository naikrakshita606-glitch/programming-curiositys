# programming-curiositys

Programming Curiosity 🚀 This repository is not about memorizing programming answers. It is about understanding WHY, WHAT, HOW, WHERE, WHEN, WHO and WHAT IF behind the technology we use every day. Every question is an opportunity to go one level deeper. Don’t just learn code. Understand what happens behind the code.

## Programming Curiosity Challenge

The purpose is to make you start asking: **“But how does this actually work?”**

Don’t search for the answers immediately. Pick questions, discuss them with your team, make your own assumptions, and then find the real answer. The challenge is now categorized in the topic files above; each file contains the questions most relevant to that subject. Question numbers 1–100 are preserved so you can follow or discuss the original sequence.

### The 10 Rabbit Hole Questions

The deeper, cross-topic investigations are grouped in [Rabbit Holes](10-rabbit-holes/):

### Whenever You Learn Something, Ask 7 Questions

**WHY? → WHAT? → HOW? → WHERE? → WHEN? → WHO? → WHAT IF?**

The topic files answer each challenge question and use these seven angles where they help explain the subject: why it matters, what it is, how it works, where it runs or is used, when it is useful, who is involved, and what can happen when conditions change or something fails.

For example, when you learn MongoDB, don’t stop at what it is. Ask why it is used, how and where it stores data, when to choose it, who uses it, and what happens if it goes down.

A good programmer doesn’t just learn answers. A good programmer develops better questions.
