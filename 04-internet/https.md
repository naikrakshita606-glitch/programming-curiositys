# HTTPS

HTTPS is HTTP carried over Transport Layer Security (TLS). It protects communication between a client and a server and helps the client verify the server's identity.

## Curiosity questions and answers

### 47. Why was HTTPS created?

Plain HTTP can be read or altered by parties able to observe or interfere with the connection. HTTPS uses TLS to encrypt data in transit, detect tampering, and authenticate the server using certificates. This is important for passwords and payments, but it does not guarantee that a site is honest, secure, or safe after data reaches it.
