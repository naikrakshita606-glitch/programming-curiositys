# Cloud Computing

Cloud computing provides on-demand access to computing resources over a network. Providers operate data centers and offer services at different levels, from virtual machines to managed databases and application platforms.

## Curiosity questions and answers

### 96. What is cloud computing?

Cloud computing lets organizations provision compute, storage, networking, and managed software without owning every physical machine. Resources can often be created or resized through a console or API and billed according to use. The customer still has responsibility for configuration, security, cost control, and application design.

### 97. What is AWS/Azure actually providing?

AWS and Microsoft Azure provide services such as virtual machines, networks, object storage, databases, identity tools, monitoring, and managed application platforms. They operate the underlying infrastructure; customers select and configure services for their workloads. The shared-responsibility model means provider and customer duties differ by service, and the customer remains responsible for many application and access-control decisions.
