# Compilers

A compiler translates a program from one representation into another, often from source code to machine code or bytecode. Translation may happen before execution, during execution, or in stages.

## Curiosity questions and answers

### 9. Why does a programming language need a compiler or interpreter?

Processors execute machine instructions, not most human-readable source languages. A compiler or interpreter implements the language's rules and turns source into operations the computer can carry out. Some languages have both: a compiler creates bytecode and a runtime interprets or just-in-time compiles it.
